# School Registration System

A Python-based school registration system using SQLite database handler.

## 📌 Features
- Student registration form
- Database handler with SQLite
- Student list management
- Simple GUI with Tkinter
- Easy to extend and customize

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/LaithYousef-bit/school_registration_system.git
2. Navigate to the project folder:
   ```bash
   cd school_registration_system
3. Install requirements:
   ```bash
   pip install -r requirements.txt
4. Run the app:
   ```bash
   python run_app.py

   
## 📂 Project Structure

- `main.py` → Entry point of the application  
- `Registerion_form.py` → Student registration form  
- `Student_List.py` → Manage and view student list  
- `database_handler.py` → SQLite database handler  
- `run_app.py` → Script to run the application  
- `.gitignore` → Ignore unnecessary files  
- `README.md` → Project documentation
